## 一句话

源片一帧不切、不上滤镜、不加任何压暗遮罩，原样全屏打底；
只在屏幕边缘叠一层**代码生成的金色信息柱**。
出镜的你不变，画面自己长出了质感。

## 它长什么样

每幕一个「信息柱」，自上而下六件，全部贴屏幕**最左边缘**：

```
金色小标签     ← 22px / 900 / 宽字距
白色主关键词   ← 84px / 900
白色副行       ← 30px / 400
金色主体       ← 196px / 900（英雄字）
金色胶囊       ← 金底深字：值 + 标签
金色刻度条     ← 44×8 小段，最多 8 段
```

右侧贴**最右边缘**放"幕内说明"；四角有常驻 HUD；整片叠一层静态颗粒。

## 三条底线（为什么它看起来"干净"）

1. **只加光，不压黑** —— 没有任何近黑渐变 / 暗角 / 降亮度。氛围靠冷调高光 + 金色发光做出来。
2. **绝不压脸** —— 人永远在画面中间，信息柱只走左右**最边边**，中间大片留给人。
3. **零外部素材** —— 每一个像素都由代码画出，不贴任何第三方图片 / 图标 / logo。

## 视觉规范速查

| 项 | 值 |
|---|---|
| 金色（唯一强调色） | `#FFD24A` |
| 蓝色（极小面积） | `#5FB8FF` |
| 主文字 | `#FFFFFF` |
| 整层统一透明度 | `0.86` |
| 字重 | 只用 400 / 700 / 900 |
| 字体 | ⚠️ 自行选一款开源可商用字体（见下方「字体」） |
| 节拍基准 | 30fps 设计帧（整片 59.94fps 自动换算） |

## 工作流

```
源片 + 逐句 SRT
   → 按语气转折切幕（每幕 5–12s）
   → 每幕配一组信息柱字段
   → 源片打底 + 逐幕叠加 + 常驻 HUD
   → 静帧预览 → 整片渲染 → 无损合源音频
```

**只改局部时**：切点取在幕边界，只重渲改动的那几幕 + 帧级拼接拼回整片，省一半以上时间。

## 字体 ⚠️

**本 skill 不提供字体落地方法** —— 字体在不同渲染环境 / 框架下做法各异，请自行处理。

- 请**自行选一款开源可商用**的中文字体（如 思源黑体 / Noto Sans SC）。
- 请**自行确认它在你的工程里真的生效** —— 以**成片**为准验证，别只看代码
  （常见坑：字体名写了但没被加载，静默回退到系统自带的商用字体）。
- 用前请**自行确认字体授权**是否允许你的用法（商用 / 嵌入 / 分发）。
