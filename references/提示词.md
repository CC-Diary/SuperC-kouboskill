# 提示词 · 口播辅助层（暗色科技风）

> 用法：把下面整段复制给 AI，**同时附上你的源片 + SRT（逐句字幕）**。
> AI 会按同一套暗色科技风，给你每一幕的信息柱文案 + 叠加层代码。
>
> ⚠️ **隐私提醒**：这一步会把你的**源片与字幕上传给你所用的 AI 服务**。
> 请自行确认该服务的**隐私与数据使用条款**（是否用于训练、是否留存、谁可访问等）；
> 涉密、涉隐私或未获授权的素材，**请勿上传**。选哪家 AI、承担什么风险，由你自己决定。

## 主提示词（直接复制）

```
你现在是一位短视频「口播辅助层」设计师。请按下面这套已经定稿的视觉范式，
为我这条实拍口播做一层叠加包装（不是剪辑、不是调色）。

【输入】
- 源片：<附上视频文件>
- 逐句字幕 SRT：<附上 SRT>
- 我的账号名：<填你的账号名，用于四角 HUD>

【这套范式是什么】
源片一帧不切、不上滤镜、不加任何压暗遮罩，原样全屏打底；
只在屏幕边缘叠加代码生成的金色信息柱，把"只有一个人 + 一条字幕"的干片
包装成有质感的成片。氛围只"加光"，不"压黑"。

【硬性铁律 —— 违反任何一条都算失败】
1. 画面里绝不出现任何压暗：不要左右近黑渐变、不要顶/底压暗、不要暗角、不要降亮度。
2. 特效绝不遮住人物的脸。人在画面中间，信息柱一律贴最左边缘、说明贴最右边缘。
3. 背景保持透明，素材原样透出来。
4. 全部文字统一用同一款**开源可商用**的中文字体（如思源黑体 / Noto Sans SC），字重只用 400 / 700 / 900。
   ⚠️ 字体在本工程里怎么落地、怎么确认真的生效 —— **我自己处理，你不用管，也不要写字体加载相关代码**。
5. 所有画面元素由代码生成，禁止贴任何第三方图片、图标、logo。
6. 一屏只出现一个信息柱，各幕时间错开，不许堆叠。
7. 不要震动、不要闪光扫过、不要平铺水印字墙。

【视觉语汇 —— 每幕一个"信息柱"，自上而下六件】
1) 金色小标签   22px / 900 / 字距 0.32em / 金 #FFD24A
2) 白色主关键词 84px / 900 / -0.03em / 白 #FFFFFF
3) 白色副行     30px / 400 / rgba(255,255,255,0.86)
4) 金色主体     196px / 900 / -0.04em / 金 #FFD24A（可按字数缩到 112–200）
5) 金色胶囊     金底深字：值 42px/900 + 竖分隔线 + 标签 26px/700
6) 金色刻度条   44×8 小段，最多 8 段
右侧另加"幕内说明"：一行白字 25px/900 + 一行小角标 17px/rgba(255,255,255,0.40)

【调色板】
金 #FFD24A · 蓝 #5FB8FF（极小面积）· 白 #FFFFFF · 暗白 rgba(255,255,255,0.62) · 微白 rgba(255,255,255,0.40)
文字阴影（三层，压在实拍上也读得清）：
0 1px 2px rgba(0,0,0,0.95), 0 3px 12px rgba(0,0,0,0.88), 0 10px 30px rgba(0,0,0,0.62)
整层统一透明度 FX = 0.86

【常驻件】
四角 HUD（左上：账号名 + 蓝色短规线；右上：REAL RECORD · 日期；右下：两行元数据），
放在整片层只淡入一次；再叠一层静态噪点颗粒 opacity≈0.06。

【节拍】
基准 30fps 设计帧。两条曲线：主关键词/金色主体用"临界阻尼落定"（永不过弹）；
副行/胶囊/刻度条用 smootherstep。每幕默认：标签 -6 · 副行 28 · 金色主体 10 · 胶囊 54 · 刻度条 62。

【请产出】
第一步：按 SRT 的语气转折切幕（每幕约 5–12 秒），列出时间轴表。
第二步：为每一幕填这组字段（用词要口语、贴住这幕真正在讲的内容，不编数字）：
  tag / keyword / keywordSub / gold / pillValue / pillLabel / footA / footB
第三步：逐幕给出叠加层的实现代码（按 1920×1080 设计坐标，输出时自动等比缩放到源片尺寸）。
```

## 换风格的口子

默认就是上面这套（暗色科技风）。若要换气质，只改"氛围走加光"这一层，**七条铁律不动**：

| 想要 | 怎么改 |
|---|---|
| 更冷 | 冷高光透明度 0.09 → 0.12，金色减到只在标签用 |
| 更亮 | FX 0.86 → 0.92（但别去掉阴影，否则压不住亮背景） |
| 换强调色 | 把 GOLD 整体换一个色，**但只保留一个强调色**，别再加第二个 |
